What it does

Grade a set of HTTP response headers and see what is missing. It runs entirely in your browser — your input never leaves your machine, so it is safe to use with data you would not paste into a hosted service.

Example input

HTTP/2 200
content-type: text/html; charset=utf-8
server: nginx/1.24.0
x-powered-by: Express
set-cookie: session=abc123; Path=/
access-control-allow-origin: *

How to use it

  1. Open Security Headers Analyser and paste or type your input.
  2. The result appears as you type.
  3. Copy the result, or save it to a file.

Things worth knowing

Scoring is a rule of thumb for comparing before and after, not an industry standard. A header being present does not mean it is correct for your app — a CSP that allows unsafe-inline looks compliant and blocks very little.

Frequently asked questions

Is Security Headers Analyser free to use?

Yes. Every tool on this site is free, needs no account, and has no usage limits.

Does Security Headers Analyser upload my data?

No. It runs entirely in your browser using JavaScript. Your input is never sent to a server, which makes it safe for data you would not paste into a hosted tool. The two exceptions across the whole site (the Azure Service Bus relay and the IP lookup) are documented and opt-in.

What should I watch out for when using Security Headers Analyser?

Scoring is a rule of thumb for comparing before and after, not an industry standard. A header being present does not mean it is correct for your app — a CSP that allows unsafe-inline looks compliant and blocks very little.

Does Security Headers Analyser work offline?

Once the page has loaded it keeps working without a connection. A few tools fetch a library on first use, after which they are cached.
