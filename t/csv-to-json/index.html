What it does

Convert CSV or TSV into JSON, with automatic delimiter detection. It runs entirely in your browser — your input never leaves your machine, so it is safe to use with data you would not paste into a hosted service.

Example input

name,age,city,active
Ada Lovelace,36,London,true
"Smith, John",42,"New York",false
Grace Hopper,85,Arlington,true

How to use it

  3. Copy the result, or save it to a file.

Frequently asked questions

Is CSV to JSON free to use?

Yes. Every tool on this site is free, needs no account, and has no usage limits.

Does CSV to JSON upload my data?

No. It runs entirely in your browser using JavaScript. Your input is never sent to a server, which makes it safe for data you would not paste into a hosted tool. The two exceptions across the whole site (the Azure Service Bus relay and the IP lookup) are documented and opt-in.

What options does CSV to JSON have?

You can configure: Delimiter, First row is a header, Convert numbers and booleans, Skip blank rows, Indent.

Does CSV to JSON work offline?

Once the page has loaded it keeps working without a connection. A few tools fetch a library on first use, after which they are cached.
