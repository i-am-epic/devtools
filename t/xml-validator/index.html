XML Validator

Well-formedness checking via the browser XML parser.

Open XML Validator →

What it does

Check XML for well-formedness and get the exact error location. It runs entirely in your browser — your input never leaves your machine, so it is safe to use with data you would not paste into a hosted service.

Example input

<catalog>
  <book id="1">
    <title>Unclosed
  </book>
</catalog>

How to use it

  1. Open XML Validator and paste or type your input.
  2. The result appears as you type.
  3. Copy the result, or save it to a file.

Things worth knowing

This checks well-formedness (tags balanced, one root, valid characters). It does not validate against a DTD or XSD schema.

Frequently asked questions

Is XML Validator free to use?

Yes. Every tool on this site is free, needs no account, and has no usage limits.

Does XML Validator upload my data?

No. It runs entirely in your browser using JavaScript. Your input is never sent to a server, which makes it safe for data you would not paste into a hosted tool. The two exceptions across the whole site (the Azure Service Bus relay and the IP lookup) are documented and opt-in.

What should I watch out for when using XML Validator?

This checks well-formedness (tags balanced, one root, valid characters). It does not validate against a DTD or XSD schema.

Does XML Validator work offline?

Once the page has loaded it keeps working without a connection. A few tools fetch a library on first use, after which they are cached.
