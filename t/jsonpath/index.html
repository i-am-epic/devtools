JSONPath Evaluator

Supports $.a.b, [*], [0], [1:3], recursive .., and simple filters like [?(@.total > 10)].

Open JSONPath Evaluator →

What it does

Query a JSON document with JSONPath and see exactly what matches. It runs entirely in your browser — your input never leaves your machine, so it is safe to use with data you would not paste into a hosted service.

Example input

{
  "id": 1042,
  "name": "Ada Lovelace",
  "active": true,
  "score": 91.5,
  "joined": "2024-03-01T09:30:00Z",
  "tags": ["maths", "computing"],
  "address": { "city": "London", "postcode": "W1A 1AA" },
  "orders": [
    { "ref": "A-1", "total": 25.5, "shipped": true },
    { "ref": "A-2", "total": 10, "shipped": false, "note": "gift" }
  ]
}

How to use it

  1. Open JSONPath Evaluator and paste or type your input.
  2. Adjust the options if you need something other than the defaults.
  3. Copy the result, or save it to a file.

Frequently asked questions

Is JSONPath Evaluator free to use?

Yes. Every tool on this site is free, needs no account, and has no usage limits.

Does JSONPath Evaluator upload my data?

No. It runs entirely in your browser using JavaScript. Your input is never sent to a server, which makes it safe for data you would not paste into a hosted tool. The two exceptions across the whole site (the Azure Service Bus relay and the IP lookup) are documented and opt-in.

What options does JSONPath Evaluator have?

You can configure: JSONPath, Unwrap a single match.

Does JSONPath Evaluator work offline?

Once the page has loaded it keeps working without a connection. A few tools fetch a library on first use, after which they are cached.
