GitHub Actions Checker

Includes the script-injection check — interpolating ${{ github.event... }} straight into a run block lets a pull request title execute code in your runner.

Open GitHub Actions Checker →

What it does

Lint a workflow for unpinned actions, script injection and missing permissions. It runs entirely in your browser — your input never leaves your machine, so it is safe to use with data you would not paste into a hosted service.

Example input

name: CI
on:
  pull_request_target:
    branches: [main]

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: some/action@main
      - name: Greet
        run: echo "Building ${{ github.event.pull_request.title }}"
      - name: Deploy
        run: ./deploy.sh
        env:
          TOKEN: ghp_hardcodedtokenvalue123456

How to use it

  1. Open GitHub Actions Checker and paste or type your input.
  2. The result appears as you type.
  3. Copy the result, or save it to a file.

Frequently asked questions

Is GitHub Actions Checker free to use?

Yes. Every tool on this site is free, needs no account, and has no usage limits.

Does GitHub Actions Checker upload my data?

No. It runs entirely in your browser using JavaScript. Your input is never sent to a server, which makes it safe for data you would not paste into a hosted tool. The two exceptions across the whole site (the Azure Service Bus relay and the IP lookup) are documented and opt-in.

Does GitHub Actions Checker work offline?

Once the page has loaded it keeps working without a connection. A few tools fetch a library on first use, after which they are cached.
