Cron Expression Parser

Five fields (minute hour day-of-month month day-of-week), or six with a leading seconds field.

Open Cron Expression Parser →

What it does

Explain a cron schedule in plain English and list the next run times. It runs entirely in your browser — your input never leaves your machine, so it is safe to use with data you would not paste into a hosted service.

Example input

30 9 * * MON-FRI

How to use it

  1. Open Cron Expression Parser and paste or type your input.
  2. Adjust the options if you need something other than the defaults.
  3. Copy the result, or save it to a file.

Things worth knowing

When both day-of-month and day-of-week are restricted, standard cron fires if either matches — a common source of surprise. Quartz extensions (L, W, #) are not supported here.

Frequently asked questions

Is Cron Expression Parser free to use?

Yes. Every tool on this site is free, needs no account, and has no usage limits.

Does Cron Expression Parser upload my data?

No. It runs entirely in your browser using JavaScript. Your input is never sent to a server, which makes it safe for data you would not paste into a hosted tool. The two exceptions across the whole site (the Azure Service Bus relay and the IP lookup) are documented and opt-in.

What options does Cron Expression Parser have?

You can configure: Next runs to show, Evaluate in UTC.

What should I watch out for when using Cron Expression Parser?

When both day-of-month and day-of-week are restricted, standard cron fires if either matches — a common source of surprise. Quartz extensions (L, W, #) are not supported here.

Does Cron Expression Parser work offline?

Once the page has loaded it keeps working without a connection. A few tools fetch a library on first use, after which they are cached.
