Timestamp Converter

Paste a Unix timestamp (seconds, milliseconds, microseconds or nanoseconds) or any date string — the unit is detected automatically. Leave it empty for "now".

Open Timestamp Converter →

What it does

Convert between Unix timestamps, ISO 8601 and human-readable dates. It runs entirely in your browser — your input never leaves your machine, so it is safe to use with data you would not paste into a hosted service.

Example input

1700000000

Options

SettingValuesNotes
Local zone displayYour local timezone, UTC only

How to use it

  1. Open Timestamp Converter and paste or type your input.
  2. Adjust the options if you need something other than the defaults.
  3. Copy the result, or save it to a file.

Frequently asked questions

Is Timestamp Converter free to use?

Yes. Every tool on this site is free, needs no account, and has no usage limits.

Does Timestamp Converter upload my data?

No. It runs entirely in your browser using JavaScript. Your input is never sent to a server, which makes it safe for data you would not paste into a hosted tool. The two exceptions across the whole site (the Azure Service Bus relay and the IP lookup) are documented and opt-in.

What options does Timestamp Converter have?

You can configure: Local zone display.

Does Timestamp Converter work offline?

Once the page has loaded it keeps working without a connection. A few tools fetch a library on first use, after which they are cached.
