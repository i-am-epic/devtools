HTML to Markdown

Headings, lists, links, tables, code blocks and emphasis are all mapped across.

Open HTML to Markdown →

What it does

Convert HTML markup into clean Markdown. It runs entirely in your browser — your input never leaves your machine, so it is safe to use with data you would not paste into a hosted service.

Example input

<h1>Release notes</h1>
<p>Shipped <strong>three</strong> things:</p>
<ul><li>Parquet viewer</li><li>Service Bus tools</li></ul>
<pre><code>const answer = 42;</code></pre>

Options

SettingValuesNotes
Heading style# ATX, Underlined (setext)
Bullet marker- dash, * asterisk, + plus

How to use it

  1. Open HTML to Markdown and paste or type your input.
  2. Adjust the options if you need something other than the defaults.
  3. Copy the result, or save it to a file.

Frequently asked questions

Is HTML to Markdown free to use?

Yes. Every tool on this site is free, needs no account, and has no usage limits.

Does HTML to Markdown upload my data?

No. It runs entirely in your browser using JavaScript. Your input is never sent to a server, which makes it safe for data you would not paste into a hosted tool. The two exceptions across the whole site (the Azure Service Bus relay and the IP lookup) are documented and opt-in.

What options does HTML to Markdown have?

You can configure: Heading style, Bullet marker.

Does HTML to Markdown work offline?

Once the page has loaded it keeps working without a connection. A few tools fetch a library on first use, after which they are cached.
