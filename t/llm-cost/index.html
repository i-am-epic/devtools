What it does

Estimate what a prompt, a batch or a month of traffic will cost. It runs entirely in your browser — your input never leaves your machine, so it is safe to use with data you would not paste into a hosted service.

Frequently asked questions

Is LLM Cost Calculator free to use?

Yes. Every tool on this site is free, needs no account, and has no usage limits.

Does LLM Cost Calculator upload my data?

No. It runs entirely in your browser using JavaScript. Your input is never sent to a server, which makes it safe for data you would not paste into a hosted tool. The two exceptions across the whole site (the Azure Service Bus relay and the IP lookup) are documented and opt-in.

What options does LLM Cost Calculator have?

You can configure: Rate preset, Input $ / 1M tokens, Output $ / 1M tokens, Input tokens (0 = measure the text), Expected output tokens.

Does LLM Cost Calculator work offline?

Once the page has loaded it keeps working without a connection. A few tools fetch a library on first use, after which they are cached.
