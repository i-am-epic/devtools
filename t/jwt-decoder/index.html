What it does

Decode a JSON Web Token and verify its HMAC signature. It runs entirely in your browser — your input never leaves your machine, so it is safe to use with data you would not paste into a hosted service.

How to use it

  1. Open JWT Decoder and paste or type your input.
  2. Adjust the options if you need something other than the defaults.
  3. Copy the result, or save it to a file.

Things worth knowing

Decoding a JWT does not authenticate it — anyone can read and rewrite the claims. Only a verified signature makes a token trustworthy, and the server must pin the expected algorithm rather than trusting the token's own alg field.
