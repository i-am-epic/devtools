CSS Checker

Runs your CSS through the browser's own parser and reports what it refused to accept.

Open CSS Checker →

What it does

Check CSS for unbalanced braces, dropped rules and empty selectors. It runs entirely in your browser — your input never leaves your machine, so it is safe to use with data you would not paste into a hosted service.

Example input

.good { color: red; }
.bad { color: ; }
.empty { }
.unclosed { background: blue;

How to use it

  1. Open CSS Checker and paste or type your input.
  2. The result appears as you type.
  3. Copy the result, or save it to a file.

Frequently asked questions

Is CSS Checker free to use?

Yes. Every tool on this site is free, needs no account, and has no usage limits.

Does CSS Checker upload my data?

No. It runs entirely in your browser using JavaScript. Your input is never sent to a server, which makes it safe for data you would not paste into a hosted tool. The two exceptions across the whole site (the Azure Service Bus relay and the IP lookup) are documented and opt-in.

Does CSS Checker work offline?

Once the page has loaded it keeps working without a connection. A few tools fetch a library on first use, after which they are cached.
