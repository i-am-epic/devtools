Chat API Payload Builder

Write the conversation in plain text; get correct JSON for the OpenAI or Anthropic API, plus a curl command.

Open Chat API Payload Builder →

What it does

Turn a system prompt and a conversation into a ready-to-send request body. It runs entirely in your browser — your input never leaves your machine, so it is safe to use with data you would not paste into a hosted service.

Example input

system: You are a concise assistant. Answer in British English.
user: What is the difference between a queue and a topic?
assistant: A queue delivers each message to exactly one consumer.
user: And a topic?

Frequently asked questions

Is Chat API Payload Builder free to use?

Yes. Every tool on this site is free, needs no account, and has no usage limits.

Does Chat API Payload Builder upload my data?

No. It runs entirely in your browser using JavaScript. Your input is never sent to a server, which makes it safe for data you would not paste into a hosted tool. The two exceptions across the whole site (the Azure Service Bus relay and the IP lookup) are documented and opt-in.

What options does Chat API Payload Builder have?

You can configure: API shape, Model, Temperature, Max output tokens, Stream the response.

Does Chat API Payload Builder work offline?

Once the page has loaded it keeps working without a connection. A few tools fetch a library on first use, after which they are cached.
